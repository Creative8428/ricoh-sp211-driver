Native driver for the Ricoh SP 211

This installs a driver for the Ricoh SP 211 printer that runs natively on Macs with Apple silicon (M1, M2, M3, M4…) and does not need Rosetta. The printer will keep working on macOS 28 and later.

What the installer does:

  • If the printer is already set up on this Mac, it is switched to the new driver automatically.
  • If the printer is connected by USB but not set up yet, it is added automatically.
  • Otherwise, add it any time in System Settings → Printers & Scanners; the driver is selected automatically.

To undo everything, use Uninstall Driver.app from the same window.
